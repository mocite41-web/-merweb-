# Facility Reservation Predictive System

## Run locally
1. Put `app.py`, `requirements.txt`, and `facility_reservations.csv` in the same folder.
2. Open Command Prompt/Terminal in that folder.
3. Run: `pip install -r requirements.txt`
4. Run: `streamlit run app.py`

The app includes Home, Dataset, Data Analysis, Prediction, Dashboard, and System Design modules.
